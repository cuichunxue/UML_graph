# UML図エディタ

**完全オフラインで動く、インタラクティブなビジュアルUMLエディタ。**
`index.html` をブラウザで開くだけ。サーバーも外部ライブラリ（CDN）も一切不要で、ネット接続がなくても動作します。

PlantUML のような「テキストを書いてサーバーで画像化する」方式ではなく、**図形を直接ドラッグして組み立てる直接操作（direct manipulation）方式**を採用しています。

## 対応する図種（上部セレクタで切替・各図は個別に保存）
- **クラス図** — クラス／属性・操作／継承・実現・依存・誘導・関連・集約・合成
- **状態遷移図** — 状態（角丸）／開始・終了疑似状態／ラベル付き遷移
- **ユースケース図** — アクター（棒人間）／ユースケース（楕円）／システム境界／include・extend・汎化
- **コンポーネント図** — «component»（コンポーネントアイコン付き）／インタフェース／依存・関連
- **シーケンス図** — ライフライン／アクター／同期（塗り矢印）・非同期・応答（破線）・自己メッセージ、時間順の自動配置、**実行仕様バー（activation）自動表示**、**複合フラグメント（alt/loop/opt/par/break/critical、altはelse対応）**

## できること
- **ノードの配置**: 左ツールでノード種別を選び → キャンバスをクリック（空白のダブルクリックでも可）
- **関連線をドラッグで接続**: 図種ごとの関連に対応
  - クラス図は 関連 / 誘導（→）/ 継承（△）/ 実現（△破線）/ 依存（→破線）/ 集約（◇）/ 合成（◆）
  - 矢じり・三角・菱形は SVG で自前描画（UML標準の見た目）
  - 同じ要素へ接続すると**自己ループ**（自己遷移・再帰的関連）として描画
- **インライン編集**: 右パネルで名前・ステレオタイプ・属性・操作・多重度・ラベルを編集
- **テキスト⇄図の双方向同期**（全5図種）: `</>テキスト` で PlantUML風コードを表示。図を編集すると即テキストへ、テキストを編集すると即図へ反映
  - クラス: `class Foo { … }` / `Dog --|> Animal` ほか
  - シーケンス: `A -> B : msg` / `alt…else…end` / `loop` / `opt`
  - 状態遷移: `[*] --> 待機` / `A --> B : event`
  - ユースケース: `actor 顧客` / `顧客 --> (ログイン)` / `(注文) ..> (ログイン) : <<include>>`
  - コンポーネント: `component "Web UI"` / `[A] ..> [B] : HTTP`
- **複数選択と整列**: Shift+クリック / Shift+ドラッグ（範囲選択）/ Ctrl+A。2件以上で左右上下揃え・中央揃え・等間隔配置
- **入れ子コンテナ**: **複合状態**（状態の中に状態）/ **パッケージ**（クラス図）/ **システム境界**（ユースケース・コンポーネント図）。ノードを内側にドラッグで所属、コンテナを動かすと中身ごと移動、自動サイズ調整。テキストでは `package X { … }` / `state X { … }` / `rectangle "X" { … }` の入れ子に対応
- **ノート（付箋）**: 全図種に注釈を配置（折り角付きの付箋、ドラッグ移動・複数行編集）。要素へ破線の**アンカー線**で接続可能
- **編集支援**: 🧲 グリッド吸着、▦ 自動整列（継承の階層レイアウト）、複製（Ctrl+D）、コピー/貼り付け（Ctrl+C / Ctrl+V）
- **移動 / パン / ズーム / 全体表示**
- **元に戻す・やり直し（Undo/Redo）**、削除
- **書き出し**: SVG / PNG（最大4x）、画像クリップボードコピー（すべてブラウザ内で完結）
- **保存・共有**: JSON 保存/読込、共有リンク（図をURLに埋め込み）、localStorage 自動保存
- **テンプレート**: 継承 / インタフェース実現 / 集約・合成 / MVC
- ライト/ダークテーマ

## ショートカット
| キー | 動作 |
| --- | --- |
| `C` | クラス追加モード |
| `V` / `Esc` | 選択モード |
| `Shift + クリック / ドラッグ` | 複数選択 / 範囲選択 |
| `Ctrl/Cmd + A` | 全選択 |
| `Ctrl/Cmd + D` | 複製 |
| `Ctrl/Cmd + C` / `V` | コピー / 貼り付け |

| 空白ドラッグ | 画面移動（パン） |

## テキスト（PlantUML風DSL）の対応構文
```
@startuml
abstract class Animal {      ' abstract / interface / class / enum
  # name: String             ' 「(」を含む行は操作、それ以外は属性
  + eat(): void
}
class Dog
Dog --|> Animal              ' 継承  （<|-- / --|>）
Dog ..|> Runnable            ' 実現  （<|.. / ..|>）
Owner "1" o-- "*" Dog : has  ' 集約（o--）多重度・ラベル付き
Car *-- Engine               ' 合成（*--）
Foo --> Bar                  ' 誘導 / Foo ..> Bar 依存 / Foo -- Bar 関連
@enduml
```
図⇄テキストは双方向に往復可能（位置はクラス名で対応付けて保持）。

## PlantUML との違い（設計方針）
| | PlantUML | 本エディタ |
| --- | --- | --- |
| 描画 | サーバー（Java）で画像化 | **ブラウザ内のSVGで即時描画** |
| 依存 | サーバー/CDN必須 | **不要（単一HTML・完全オフライン）** |
| 編集 | テキスト記述 | **図形を直接ドラッグ操作** |
| レイアウト | 自動（手で動かせない） | **自由配置（ドラッグで好きな位置へ）** |
| 書き出し | サーバー経由 | **クライアントのみでSVG/PNG** |
| データ | テキスト | JSON（可搬・差分管理しやすい） |

## 技術メモ
- 依存ライブラリ・ビルド不要。`index.html` 単体。
- 図は `<svg>` を DOM 操作でリアルタイム描画。書き出し時はテーマ色を `<style>` に埋め込んだ自己完結SVGを生成するため、PNG ラスタライズ時に canvas が汚染（taint）されず確実に成功します。
- データモデル: `{ nodes: [{id,x,y,name,stereotype,attributes[],methods[]}], edges: [{id,from,to,type,fromMult,toMult,label}] }`
