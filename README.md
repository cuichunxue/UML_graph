# UMLクラス図エディタ

**完全オフラインで動く、インタラクティブなビジュアルUMLクラス図エディタ。**
`index.html` をブラウザで開くだけ。サーバーも外部ライブラリ（CDN）も一切不要で、ネット接続がなくても動作します。

PlantUML のような「テキストを書いてサーバーで画像化する」方式ではなく、**図形を直接ドラッグして組み立てる直接操作（direct manipulation）方式**を採用しています。

## できること
- **クラスの配置**: 「クラス追加」ツール → キャンバスをクリック（空白のダブルクリックでも可）
- **関連線をドラッグで接続**: UML 7種に対応
  - 関連 / 誘導（→）/ 継承（△）/ 実現（△破線）/ 依存（→破線）/ 集約（◇）/ 合成（◆）
  - 矢じり・三角・菱形は SVG で自前描画（UML標準の見た目）
- **インライン編集**: 右パネルでクラス名・ステレオタイプ・属性・操作・多重度・ラベルを編集
- **移動 / パン / ズーム / 全体表示**
- **元に戻す・やり直し（Undo/Redo）**、削除
- **書き出し**: SVG / PNG（最大4x）、画像クリップボードコピー（すべてブラウザ内で完結）
- **保存・共有**: JSON 保存/読込、共有リンク（図をURLに埋め込み）、localStorage 自動保存
- **テンプレート**: 継承 / インタフェース実現 / 集約・合成 / MVC
- ライト/ダークテーマ

## ショートカット
| キー | 動作 |
| --- | --- |
| `C` | クラス追加モード |
| `V` / `Esc` | 選択モード |
| `Delete` / `Backspace` | 選択を削除 |
| `Ctrl/Cmd + Z` | 元に戻す |
| `Ctrl/Cmd + Shift + Z` | やり直し |
| `Shift + F` | 全体表示 |
| ホイール | 拡大縮小 |
| 空白ドラッグ | 画面移動（パン） |

## PlantUML との違い（設計方針）
| | PlantUML | 本エディタ |
| --- | --- | --- |
| 描画 | サーバー（Java）で画像化 | **ブラウザ内のSVGで即時描画** |
| 依存 | サーバー/CDN必須 | **不要（単一HTML・完全オフライン）** |
| 編集 | テキスト記述 | **図形を直接ドラッグ操作** |
| レイアウト | 自動（手で動かせない） | **自由配置（ドラッグで好きな位置へ）** |
| 書き出し | サーバー経由 | **クライアントのみでSVG/PNG** |
| データ | テキスト | JSON（可搬・差分管理しやすい） |

## 技術メモ
- 依存ライブラリ・ビルド不要。`index.html` 単体。
- 図は `<svg>` を DOM 操作でリアルタイム描画。書き出し時はテーマ色を `<style>` に埋め込んだ自己完結SVGを生成するため、PNG ラスタライズ時に canvas が汚染（taint）されず確実に成功します。
- データモデル: `{ nodes: [{id,x,y,name,stereotype,attributes[],methods[]}], edges: [{id,from,to,type,fromMult,toMult,label}] }`
