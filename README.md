# UML図エディタ (PlantUML)

ブラウザだけで動く **PlantUML（UML）図エディタ**。Mermaid図エディタを参考に、UMLの各種図を扱えるようにした単一HTMLアプリです。

`index.html` を開くだけで動作します（図の描画には PlantUML 公式サーバーを利用するためインターネット接続が必要）。

## 対応する図
- クラス図 / オブジェクト図 / パッケージ図
- シーケンス図
- ユースケース図
- アクティビティ図
- 状態遷移図
- コンポーネント図 / 配置図
- ER図（entity）
- マインドマップ / ガント図 / JSONデータ ほか PlantUML 全般

## 主な機能
- リアルタイムプレビュー（入力をデバウンスして自動描画）
- パン / ズーム / 全体表示
- SVG / PNG（最大4x）書き出し、画像のクリップボードコピー
- テンプレート挿入、`.puml` ファイルの読込・保存
- 共有リンク（コードをURLハッシュに埋め込み）
- 入力の自動保存（localStorage）、ライト/ダーク切替

## 仕組み
入力した PlantUML テキストをエンコードして `https://www.plantuml.com/plantuml/svg/<enc>` から SVG を取得します。
エンコードは `pako`（deflate）が読み込めればコンパクトな圧縮形式を、読み込めなければ無依存の `~h` 16進形式を用います。
`@startuml` が無い場合は自動的に補完します。

## ショートカット
| キー | 動作 |
| --- | --- |
| Ctrl/Cmd + Enter | レンダリング実行 |
| Tab | インデント挿入 |
| Shift + F | 全体表示 |
| マウスホイール | 拡大縮小 |
| ドラッグ | パン（移動） |
